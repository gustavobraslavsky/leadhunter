⚙️ Configuración de LeadHunter

Necesitás una API key de Google Places para buscar negocios por rubro.

1

Crear proyecto en Google Cloud

Andá a Google Cloud Console, creá un proyecto nuevo con nombre LeadHunter y hacé click en "Create".

2

Habilitar Places API (New)

Andá a Places API y hacé click en "Enable".

3

Crear API Key

Andá a Credentials → "+ Create Credentials" → "API Key". Copiá la key.

4

Activar billing (gratis)

Andá a Billing y linkeá una tarjeta. Nuevo usuarios reciben $300 USD de crédito gratis (90 días, ~10,000 búsquedas).

5

Pegá tu API Key acá
